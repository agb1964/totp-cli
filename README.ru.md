## ✨ Возможности

- 🔑 **Генерация секретов Base32**: генерация криптографически стойких 160-битных (20 байт) секретов в формате Base32.
- 📱 **QR-код в терминале**: мгновенная отрисовка компактного Unicode QR-кода прямо в консоли для быстрого сканирования мобильным приложением.
- 🔗 **Стандартные otpauth URI**: поддержка формата `otpauth://totp/{Issuer}:{Account}?secret=...&issuer={Issuer}`.
- ⏱️ **Строгое соответствие RFC 6238**:
  - Алгоритм: **HMAC-SHA1**
  - Длина кода: **6 цифр**
  - Шаг времени (Time Step): **30 секунд**
  - Допустимый дрейф времени (Skew): **±1 интервал** (±30 секунд для компенсации рассинхронизации часов).
- 🤖 **Удобная интеграция в скрипты и CI/CD**: предсказуемые коды завершения (exit codes) для автоматизации проверок.
- ⚡ **Нулевые накладные расходы**: чистый и быстрый бинарный файл на Rust без лишних зависимостей.

## 📦 Установка

### Вариант 1: Скачать готовый бинарник (Рекомендуется)

Вы можете скачать предсобранный исполняемый файл для вашей операционной системы со страницы [**Releases**](https://github.com/agb1964/totp-cli/releases):

| Платформа | Архитектура | Архив |
| --- | --- | --- |
| 🐧 **Linux** | x86_64 | `totp-cli-linux-x86_64.tar.gz` |
| 🍏 **macOS** | Apple Silicon (arm64) | `totp-cli-macos-arm64.tar.gz` |
| 🪟 **Windows** | x86_64 | `totp-cli-windows-x86_64.zip` |

#### Быстрая установка в терминале (Linux / macOS)

```bash
# 1. Скачать архив для вашей системы (пример для Linux x86_64):
curl -LO https://github.com/agb1964/totp-cli/releases/latest/download/totp-cli-linux-x86_64.tar.gz

# Для macOS Apple Silicon (M1/M2/M3/M4):
# curl -LO https://github.com/agb1964/totp-cli/releases/latest/download/totp-cli-macos-arm64.tar.gz

# 2. Распаковать
tar -xzf totp-cli-*.tar.gz

# 3. Переместить в директорию с исполняемыми файлами
sudo mv totp-cli /usr/local/bin/
chmod +x /usr/local/bin/totp-cli
```

### 1. Генерация нового секрета и QR-кода

Команда `generate` создает новый Base32-секрет, формирует URI для аутентификатора и выводит QR-код в терминал:

```bash
totp-cli generate --issuer "GitHub" --account "user@example.com"
```

**Параметры:**

- `--issuer` (опционально, по умолчанию: `totp-cli`): название сервиса или компании.
- `--account` (опционально, по умолчанию: `user`): идентификатор/email пользователя.

### 2. Верификация одноразового кода

Команда `verify` проверяет 6-значный код для указанного Base32-секрета с учетом допустимого дрейфа времени:

```bash
totp-cli verify --secret "64R5AC5CH464NCKPVT724WRY5BYIXZJW" --code "123456"
```

**Параметры:**

- `--secret`: секрет в формате Base32.
- `--code`: 6-значный цифровой код из приложения.

**Пример успешной проверки:**

```text
Успешно (код валиден)
```

*(код возврата: `0`)*

**Пример неуспешной проверки:**

```text
Ошибка (код неверен или просрочен)
```

*(код возврата: `1`)*

## 🚦 Коды возврата (Exit Codes)

Утилита возвращает стандартные коды завершения, что упрощает её использование в Bash/Zsh-скриптах и пайплайнах:

| Код | Описание |
| :---: | :--- |
| `0` | **Успех**: код TOTP верен и актуален (или генерация секрета завершена успешно). |
| `1` | **Отказ**: код неверен, просрочен или не прошел валидацию. |
| `2` | **Ошибка параметров / выполнения**: невалидный Base32-секрет, неверный формат кода (не 6 цифр) или сбой системного времени. |

### Пример использования в Bash-скрипте

```bash
#!/usr/bin/env bash

SECRET="64R5AC5CH464NCKPVT724WRY5BYIXZJW"
read -r -p "Введите 6-значный код 2FA: " CODE

totp-cli verify --secret "$SECRET" --code "$CODE"
STATUS=$?

if [ $STATUS -eq 0 ]; then
    echo "✅ Доступ разрешен!"
elif [ $STATUS -eq 1 ]; then
    echo "❌ Неверный или устаревший код."
else
    echo "⚠️ Ошибка ввода параметров."
fi
```
