## [0.1.0] - 2026-08-26

### Добавлено

- Базовая реализация консольной утилиты `totp-cli` на базе `clap v4`.
- Команда `generate` для генерации криптографически стойких 160-битных Base32-секретов, otpauth URI и отрисовки компактного QR-кода в терминале.
- Команда `verify` для проверки 6-значных одноразовых кодов с настраиваемым дрейфом времени (±1 интервал по 30 секунд).
- Полная совместимость со спецификацией RFC 6238 (включая проверку официального тестового вектора).
- Набор модульных тестов с 100% покрытием основных сценариев работы и обработки ошибок.
- Настройка GitHub Actions CI/CD для кроссплатформенного тестирования и сборки бинарных файлов.
- Шаблоны GitHub Issue, PR и конфигурация Dependabot.
- Подробная документация в README.md и двойное лицензирование MIT / Apache-2.0.
