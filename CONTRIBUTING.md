# Руководство по участию в разработке (Contributing Guide)

Спасибо за интерес к проекту **totp-cli**!

> [!NOTE]
> Автор достиг поставленных целей в рамках данного проекта и не планирует его дальнейшее активное развитие. Репозиторий открыт, стабилен и доступен под лицензией MIT — вы можете свободно использовать его, вносить изменения или развивать собственные форки.

---

## 🛠️ Подготовка окружения

1. Убедитесь, что у вас установлен **Rust** актуальной стабильной версии:

   ```bash
   rustup update stable
   rustup component add clippy rustfmt
   ```

2. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/agb1964/totp-cli.git
   cd totp-cli
   ```

---

## 🧪 Проверка перед отправкой Pull Request

Перед созданием Pull Request убедитесь, что все автоматические проверки проходят локально:

1. **Unit-тесты**:

   ```bash
   cargo test
   ```

2. **Линтер Clippy** (без предупреждений):

   ```bash
   cargo clippy --all-targets -- -D warnings
   ```

3. **Форматирование кода**:

   ```bash
   cargo fmt --check
   ```

   (Для автоматического форматирования выполните `cargo fmt`).

---

## 🔀 Процесс внесения изменений

1. Создайте отдельную ветку для вашей задачи:

   ```bash
   git checkout -b feature/my-new-feature
   # или
   git checkout -b fix/issue-description
   ```

2. Внесите изменения и добавьте тесты для новой функциональности при необходимости.
3. Оформите понятные коммиты согласно соглашению [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat: ...` — новая функциональность
   - `fix: ...` — исправление ошибки
   - `docs: ...` — документация
   - `refactor: ...` — рефакторинг
   - `test: ...` — добавление или правка тестов
   - `ci: ...` — настройка CI/CD
4. Создайте Pull Request в ветку `main` или развивайте собственный форк.

## 🚀 Публикация релиза и создание тега

Релизы на GitHub создаются автоматически через GitHub Actions ([release.yml](.github/workflows/release.yml)) при отправке Git-тега с префиксом `v*`.

### Команда для создания и отправки тега по версии из `Cargo.toml`

```bash
# Автоматически извлекает версию из Cargo.toml, создает тег и отправляет его:
VERSION=$(grep '^version' Cargo.toml | head -n1 | cut -d '"' -f2)
git tag -a "v$VERSION" -m "Release v$VERSION"
git push origin "v$VERSION"
```

После пуша тега GitHub Actions автоматически скомпилирует бинарники для Linux, macOS и Windows и опубликует релиз.

## 📋 Стандарты кода

- Код должен быть идиоматичным для Rust.
- Публичные интерфейсы и ключевые функции должны иметь документационные комментарии (`///`).
- Не допускается использование `unsafe` без строгой необходимости и обоснования.
- Все предупреждения компилятора и clippy должны быть устранены.
